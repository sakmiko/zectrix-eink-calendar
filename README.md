# ZECTRIX E-Ink Monthly & Lunar Calendar

适用于 **ZECTRIX NOTE4** 物理设备的纯 Rust 400×300 1-bit 单色电子墨水屏月度与农历黄历日历系统。具备精准像素排版、高覆盖点阵字库、毫秒级画面哈希防抖、零点跨天自动推送、HTTP 探活与外部即时控制能力。

---

## 核心特性

- **纯 Rust 零外部图形库依赖**：基于内存帧缓冲（`Vec<u8>`）逐像素绘制，内置抗锯齿粗细线条、七段数码管、斜角卡片边框、点状网格与二值半色调进度条算法。
- **400×300 黄金分割排版**：
  - **极窄边距顶栏 (394×24px)**：严密对齐下方区域，集成设备品牌、模块指示及当前页面通道与时区标识。
  - **左侧今日黄历卡 (130×265px)**：包含年份月份季度、干支生肖、超大今日号数框、农历月日、月相、星期、干支日柱、周数、本月余天、本月流转进度条与全年进度条。
  - **右侧当月矩阵卡 (259×265px)**：标准 7×6 日历网格（单元格 36×35px），文字下移居中，完整显示公历号数、农历日/节气/节日副标题、今日黑底反色反白高亮、历史日期折角标记。
  - **底部当月节候速览栏**：智能汇聚当月全部公历/传统节日与二十四节气。
- **高覆盖率 12×12 点阵字库**：
  - 精准覆盖二十四节气、全天干地支、十二生肖、农历月日、月相、全部公历与农历传统节日、界面词汇及运维状态汉字（超 210 字独立手工适配）。
  - 内置通用缺字防崩塌 Fallback 机制（点阵空心方框 `□`），杜绝隐蔽吞字与错位。
  - 具备 1900–2050 年全量日期点阵覆盖率自动化单元测试。
- **绝对正确的历法与天文推算**：
  - 1900–2100 年共 201 年高精度农历编算历表，支持大小月与闰月精准计算。
  - 寿星天文历二十四节气算法，精确计算交节气公历日期。
  - 严格以北京时间（Asia/Shanghai，UTC+8）为基准换算，支持 NTP 校时与夏令时/时钟跳变自适应。
- **多通道隔离与通道保护**：
  - 支持第 1、2、4、5 页面通道，硬件级页面切换。
  - 默认拦截已被 Codex 额度监控雷达独占的第 3 页面；仅显式配置 `ALLOW_PAGE_3_OVERRIDE=true` 时允许覆写。
- **外部 HTTP 探活与实时控制 API**：
  - 仅监听本机 loopback 地址（默认 `127.0.0.1:9596`），提供健康状态探针与即时刷新端点。远程使用需通过 SSH/Tailscale 转发，不应暴露无鉴权的控制 API。
  - 支持直接拉取当前 400×300 实时渲染 PNG 图像流供远程诊断。

## CLI 交互控制模式 (跨平台支持 Windows & Linux)

本伴侣程序原生支持多种 CLI 控制命令：

```bash
# 1. 帮助与版本说明
zectrix_calendar_companion --help
zectrix_calendar_companion --version

# 2. 本地离线渲染指定日期月历并导出 400x300 PNG 预览图 (不产生网络请求)
zectrix_calendar_companion --preview 2026-10-21 calendar_preview.png

# 3. 本地探活检查 (通过控制端探针查询当前状态)
zectrix_calendar_companion --check

# 4. 立即触发月历重新渲染并推送上屏
zectrix_calendar_companion --trigger-refresh

# 5. 指定环境配置文件运行
zectrix_calendar_companion --env /path/to/.env
```

## 环境变量配置说明

请参考根目录下的 `.env.example` 文件：

| 变量名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `ZECTRIX_DEVICE_ID` | `AA:BB:CC:DD:EE:FF` | ZECTRIX NOTE4 物理设备 MAC/ID |
| `ZECTRIX_PAGE_ID` | `1` | 推送页面通道（1、2、4 或 5；3 已被 Codex 独占） |
| `ZECTRIX_API_BASE` | `https://cloud.zectrix.com` | 极趣云开放 API 服务基地址 |
| `ZECTRIX_API_KEY` | *(无)* | 极趣云 API 认证密钥（直接注入） |
| `ZECTRIX_API_KEY_FILE`| *(无)* | 密钥文件路径（读取文件第一行有效内容） |
| `CONTROL_LISTEN` | `127.0.0.1:9596` | 内部控制与探针监听地址（设为空则关闭） |
| `CALENDAR_MAX_FAIL_STREAK` | `5` | 连续推送失败触发自愈重启的阈值次数 |
| `ALLOW_PAGE_3_OVERRIDE` | `false` | 是否强制允许覆写第 3 页（慎用） |
| `CALENDAR_PREVIEW_PATH` | *(无)* | 每次推送时同步写出本地预览 PNG 文件路径 |

## 命令行接口 (CLI)

编译输出的执行程序为 `zectrix_calendar_companion`：

### 1. 本地生成月历预览图 (无需网络与设备密钥)
```bash
# 生成当前日期的 400x300 预览图 (输出至 calendar_preview.png)
cargo run --bin zectrix_calendar_companion -- --preview

# 生成指定日期的预览图并保存至指定文件
cargo run --bin zectrix_calendar_companion -- --preview 2026-10-15 preview.png
```

### 2. 外部运行状态与探针健康检查
```bash
cargo run --bin zectrix_calendar_companion -- --check
```

### 3. 外部触发即时刷新上屏
```bash
cargo run --bin zectrix_calendar_companion -- --trigger-refresh
```

### 4. 单次推送模式 (Run-Once)
推送当前月历至设备后立即退出（适合通过外部 systemd timer 或 cron 调用）：
```bash
cargo run --bin zectrix_calendar_companion -- --once
```

### 5. 守护进程模式 (默认)
长期驻留后台，北京时间每天 24:00 自动重绘推送，并监听 HTTP 控制接口：
```bash
cargo run --bin zectrix_calendar_companion
```

## HTTP 控制与健康检查接口

当 `CONTROL_LISTEN` 开启时，服务暴露以下 HTTP 探针与控制接口：

| 方法与路径 | 返回状态 | 说明 |
| :--- | :--- | :--- |
| `GET /healthz` 或 `GET /status` | `200 OK` / `503 Service Unavailable` | 返回 JSON 健康状态报告（包含设备 ID、通道、最近推送日期、连续失败数、距零点秒数等） |
| `POST /refresh` 或 `GET /refresh` | `200 OK` | 即刻打断等待，强制重绘当前月历并推送到设备 |
| `POST /page?id=N` | `200 OK` / `400 Bad Request` | 动态切换月历绑定的页面通道（1/2/4/5）并立即刷新上屏 |
| `GET /preview.png` | `200 OK` (`image/png`) | 实时现场渲染 400×300 墨水屏二值图像流返回，便于远程可视化审查 |
